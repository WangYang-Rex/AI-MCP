# 《魔兽世界：无限》(WoW Forever) 德鲁伊全能指南

> **版本背景：** 永久 60 级锁定、永久禁飞、重做职业天赋树、内置 40 级双天赋及野外露营篝火系统。

---

## 一、 核心职业机制改动与定位

德鲁伊是无限服重做受益最大的全能职业，补齐了原版 60 级的多项硬伤，实现了真正的“一职多修”：

1. **常规脱战复活（起死回生）：** 12 级即可直接学习无 CD 常规复活技能，彻底解决 5 人本无法救人的历史痛点。
2. **核心天赋下放为基础技能：**
   * **清晰预兆：** 20 级全系自动学习，大幅缓解能量与蓝量压力。
   * **自然之握：** 10 级基础受击缠绕保命技。
3. **变身形态现代化：**
   * 大多数药水、工程手雷/火箭靴、种族特长（如牛头人战争践踏）均可**在动物形态下直接使用**，无需解除变身。
   * **树皮术**全形态可用且无蓝耗；猫形态能量恢复改为平滑连续恢复。
4. **四系专精全面强化：**
   * **熊坦：** 新增【割伤】叠流血仇恨，护甲与血量极高，容错率全服顶尖。
   * **奶德：** 引入群体 Hot 神技【野性成长】，5 人本与团刷能力跻身 T0。
   * **鸟德：** 引入【日蚀/月蚀】联动并大幅降低耗蓝，告别“空蓝鸟”。

## 二、 种族与专业搭配

### 1. 种族选择
* **部落（牛头人）：** 部落唯一可选种族。被动【体魄】+5% 生命值（熊形态收益极大），自带 2 秒【战争践踏】硬控，变身状态下可随时踩晕接加血或缠绕。
* **联盟（暗夜精灵）：** 联盟唯一可选种族。【影遁】配合吃喝是野外永动机，+1% 基础闪避对熊坦与猫德极佳。

### 2. 专业技能推荐
* **首选方案：采药 + 炼金术（契合度 100%）**
  * 德鲁伊拥有全游戏最强的跑图与潜行采集效率（旅行形态 40% 移速、水栖形态水下高速、猎豹潜行进洞摸草）。
  * 炼金产出的合剂与精油可直接投入无限服的**露营篝火**，为全队提供高额属性与回蓝增益。
* **练级过渡技巧：** 1–40 级建议先学 **采药 + 剥皮**，沿途材料直接卖店或挂拍卖行，攒够 40 级小马和开启双天赋（约 50 金）的资金；40 级或满级后再洗掉剥皮冲炼金（或工程学）。

## 三、 天赋加点路线（任务练级 + 兼顾副本）

推荐主修 **野性战斗（42 点）/ 恢复（9 点）**。一套天赋即可实现：野外变猫零坐地板打怪，进本穿皮甲变熊当主坦，换上智力精神布甲即可客串 5 人本奶妈。

### 升级加点顺序
1. **Lv 10–14：** 野性第一层【凶暴】点满（5/5）—— 降低变身技能怒气/能量消耗，核心质变。
2. **Lv 15–19：** 野性第二层【野性本能】（3/5）+【野蛮冲撞】（2/2）—— 提高潜行等级与拍晕时间。
3. **Lv 20–21：** 20 级学会猫形态，第一时间点满第三层【豹之迅捷】（2/2）—— 户外移速 +30%，跑图起飞。
4. **Lv 22：** 第四层【野性冲锋】（1/1）—— 打断施法、瞬间近身神技。
5. **Lv 23–25：** 第三层【厚皮】（3/5 或 5/5）+ 第四层【锋利兽爪】（3/3）—— 提升护甲与暴击。
6. **Lv 26–40：** 依次点出【血之狂暴】、【原始狂怒】等暴击回怒/回能天赋，40 级点出底层光环大招 **【兽群领袖】（1/1）**。
7. **Lv 41–45：** 转投恢复系第一层，点满 **【激怒】（5/5）**，确保进本变熊瞬间自带 10 点怒气开怪。

> **40 级双天赋规划：** 主天赋保留上述**野性战斗（熊/猫）**；次天赋洗出**纯恢复系（奶德）**，用于 50+ 高压五人本及团队副本秒排进组。

## 五、 CurseForge 插件配置清单 (Mac / PC 通用)

### 1. 必装核心插件
* **Questie：** 任务指引与地图标记（确保附带 `QuestieDB`）。
* **What's Training?：** 在法术书预览后续每一级可学的新技能及花费，避免盲目回城。
* **Leatrix Maps (Classic)：** 去除地图迷雾、自由缩放、显示精确坐标。
* **Leatrix Plus (Classic)：** 自动修装、自动卖灰装、极速拾取等便民功能合集。
* **TomTom：** 输入 `/way xx yy` 生成 3D 导航箭头，配合坐标跑图。
* **Auctionator：** 悬停物品显示拍卖行参考价与卖店价，一键低价上架。
* **DBM 全套：** 必须同时安装 **`DBM-Core`** + **`DBM - SoD and Vanilla`** + **`DBM Voicepack - VV`**（中文女声语音包，进游戏输入 `/dbm` 激活）。

### 2. 进阶选装与互斥说明
* **Plater Nameplates：** 现代头顶血条，熊坦拉怪仇恨变色极度清晰。
* **Details! Damage Meter：** 伤害、承受伤害与打断统计。
* **WeakAuras (WA)：** 职业能量与状态监控（需在 CurseForge 右上角切换至 `Classic` 分类下载本体）。
* **Spy Classic：** 野外敌对玩家与潜行雷达，防抓神器。
* *避坑提示：* `Bagnon` 与 `Baganator` 选其一即可；`DBM` 与 `BigWigs` 切勿同时安装；一体化界面 `EllesmereUI` 会替代背包与血条，若喜欢原生怀旧界面则无需安装。

## 六、 德鲁伊实用宏命令合集

### 1. 智能三合一移动形态（跑图 & 解定身/减速）
自动识别环境（水中变水栖、室内变猎豹、室外变旅行），被减速或定身时连按可解除控制。
```lua
#showtooltip
/cancelform [swimming,noform:2][noswimming,indoors,noform:3][noswimming,outdoors,noform:4]
/cast [swimming] !水栖形态; [indoors] !猎豹形态; !旅行形态
```

### 2. 熊 / 猫 一键互切（省键位核心）
```lua
#showtooltip
/cancelform [noform:1,noform:3]
/cast [form:1] 猎豹形态; 巨熊形态
```

### 3. 树皮术 + 自然之握 二合一保命（全形态可用）
```lua
#showtooltip [mod:shift] 自然之握; 树皮术
/cast [mod:shift] 自然之握; 树皮术
```

### 4. 变猫 + 潜行（非战斗防误触，需连按两下）
```lua
#showtooltip 潜行
/cast [noform:3] 猎豹形态
/cast [form:3,nocombat] !潜行
```

### 5. 潜行毁灭 / 常规撕碎二合一
```lua
#showtooltip [stealth] 毁灭; 撕碎
/startattack [nostealth,harm,nodead]
/cast [stealth] 毁灭; 撕碎
```

### 6. 鼠标指向变熊野性冲锋（打断与救场）
```lua
#showtooltip 野性冲锋
/cancelform [noform:1]
/cast [noform:1] 巨熊形态
/cast [@mouseover,harm,nodead][harm,nodead] 野性冲锋
```

### 7. 鼠标指向低吼（熊坦防 OT 嘲讽）
```lua
#showtooltip 低吼
/cast [@mouseover,harm,nodead][harm,nodead] 低吼
```

### 8. 智能战复 / 脱战常规复活合一
战斗中自动施放【复生】，脱战后自动施放不耗材料的【起死回生】。
```lua
#showtooltip [combat] 复生; 起死回生
/cancelform
/cast [combat,@mouseover,help,dead][combat,help,dead] 复生; [nocombat,@mouseover,help,dead][nocombat,help,dead] 起死回生
```

### 9. 鼠标指向回春术（边跑边奶，可替换技能名通用）
```lua
#showtooltip 回春术
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 回春术
```

### 10. 鼠标指向驱除诅咒 / 驱毒术合一
```lua
#showtooltip [mod:shift] 驱毒术; 驱除诅咒
/cancelform
/cast [mod:shift,@mouseover,help,nodead][mod:shift,help,nodead][mod:shift,@player] 驱毒术; [@mouseover,help,nodead][help,nodead][@player] 驱除诅咒
```
