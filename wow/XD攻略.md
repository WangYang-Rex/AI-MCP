## 现状
目前10级，在黑海岸，刚学会变熊

### 一、 核心定位、无限服机制与天赋路线

* **核心定位**：野性战斗（猫 / 熊双修）。打怪无蓝耗、零地板坐喝时间，野外豹形态高机动输出，地下城切熊形态秒排坦克；40 级开启双天赋后可副修【恢复】秒排奶德。
* **无限服特性（永久 60 禁飞 / 重做机制）**：
  * **基础技能下放**：10 级【自然之握】、12 级常规脱战复活【起死回生】（解决 5 人本无法救人痛点）、20 级【清晰预兆】。
  * **形态现代化**：多数药水与工程道具可在动物形态直接使用；【树皮术】全形态可用且无蓝耗；猫德能量平滑连续恢复；熊坦新增【割伤】、奶德新增【野性成长】、鸟德有【日蚀/月蚀】。
  * **系统福利**：40 级内置双天赋；支持野外【露营篝火】系统提供全队属性与回蓝增益。
* **种族优势**：暗夜精灵自带“影遁”（脱战、喝水保命、辅助潜行）与“难觅踪迹”（+1% 闪避，提升熊坦生存）。
* **天赋加点路线（野性战斗 42 / 恢复 9 或 14/32/5 续航流）**：
  * **10～20 级（近战基石）**：主点野性系【凶暴 5/5】（降怒气/能量消耗）、【野蛮冲撞】与 20 级必点【野性冲锋 1/1】（冲锋打断控场）。
  * **21～30 级（猫形态爆发）**：点出【猎豹迅捷 2/2】（室外移速+30%，跑图神器）、【锋利兽爪 3/3】（+6% 暴击）、【原始狂怒 2/2】与【掠食者的打击 3/3】（巨额攻击强度提升），视抗压情况补【厚皮】。
  * **31～40 级（成型大招）**：点出【野性精灵之火 1/1】（远程破甲引怪）、【野性之心 5/5】（力量/耐力百分比质变）、40 级终极技能【兽群领袖 1/1】（团队+3% 近战物理暴击光环）。
  * **41～60 级（续航与双天赋）**：转恢复系补满【激怒 5/5】（变身秒给怒气/能量）；余下点数按无限服重做天赋树补足野性或平衡续航天赋，并利用 40 级双天赋洗出纯【恢复】备战 50+ 高压副本。

### 三、 装备选择逻辑与 10～30 级获取清单

#### 1. 属性选择核心法则

* **优先级**：**力量 = 敏捷 > 耐力 > 精神 > 智力**（日常优先穿“灵猴之/猛虎之”皮甲；包里常备 5～6 件高智精布甲可随时客串 5 人本奶妈）。
* **野德武器铁律**：变身形态下的攻速与平砍伤害固定，**完全不吃武器白字伤害和秒伤（DPS）**，武器只作为“属性发射器”，只看上面附带的力量、敏捷、耐力与攻强。

#### 2. AH 制皮购买 vs 任务与副本获取对比

* **拍卖行（AH）策略**：专治“稀缺空白部位”，趁制皮师冲技能时以极低价格捡漏（单件控制在几十银以内，攒钱 40 级买小马），避开衣服、裤子等任务白嫖部位。
* **任务 / 副本策略**：武器、高敏捷胸甲与护腿通过必做任务和下本获取，属性大幅碾压同级绿装。

#### 4. 练级消耗品与必买推荐（性价比极高）

* **常备基础**：
  * **轻型 / 中型护甲片**：贴在胸、腿、手、脚 4 件上（享受熊形态护甲加成，AH 几铜一个）。
  * **急救绷带（亚麻 $\to$ 绒线）**：残血拍晕或“影遁”脱战后直接回满，省蓝留怒。
  * **治疗药水（红瓶）**：包里常备 5～10 瓶应急保命。
* **炼金药剂（1 小时，死亡消失，AH 冲技能副产物极便宜）**：
  * **加护甲**：`初级防御`（1 级/+50 护甲）$\to$ `防御药剂`（16 级/+150 护甲，死矿神药）$\to$ `强效防御`（28 级/+250 护甲，诺莫瑞根/血色）。
  * **加血量**：`初级坚韧`（2 级/+27 血）$\to$ `坚韧药剂`（25 级/+120 血，等价 +12 耐力）。
  * **输出 / 回血**：`初级 / 次级敏捷药剂`（+暴击/攻强/闪避）；`弱效 / 强力巨魔之血药水`（1/15 级，每 5 秒回 2/6 血，野性形态生效且可与护甲/血量药剂同开）。
* **卷轴 / 食物 / 酒类（可与药剂叠加，死亡消失）**：
  * **耐力 / 保护卷轴（30 分钟）**：暴风城商人（如 Adair Gilroy）或掉落获取。耐力卷轴 I/II/III（+4/+8/+12 耐力，与牧师韧取高覆盖）；保护卷轴 I/II/III（+60/+120/+180 护甲，**可与防御药剂叠加**）。
  * **烹饪食物（15 分钟）**：吃满 10 秒获“进食充分”（如瘦狼排/热狼排/烤狮排，+4～+12 耐力与精神）。
  * **黑标朗姆酒（15 分钟）**：+15 耐力（150 血），不占食物与药剂位，AH 便宜时下本抗 Boss 可备。
* **抗精英 / 下本满配叠加公式**：**防御药剂 + 坚韧药剂 + 耐力/保护卷轴 + 烹饪食物**（+ 可选黑标朗姆酒）互不冲突。*注：药剂临时护甲不吃熊形态装备护甲百分比放大，直接按面板数值实打实加在最终护甲上。*

### 四、 实战操作与细节备忘

1. **变身永动循环**：开怪前人形套【回春术】/【荆棘术】 $\to$ 变熊拍槌击或变猫撕扯输出 $\to$ 近战平砍与技能消耗怒气/能量，此时人形依照“5秒规则”自动回蓝 $\to$ 怪死后变回人形加一口血再变回野兽，达成零坐地板永动。
2. **无限服专属成长礼包**：每逢 10 级、20 级等整十等级，经过主城时留意邮箱与新手导师，领取无限服提供的成长道具、背包及货币福利。

### 五、 前期赚钱与省钱指南（攒 40 级 40～50 金小马）

1. **双采专业（首选剥皮 + 采药/采矿，避开制造系吞金专业）**：
   * **剥皮**：练级主刷野兽怪，打完零绕路剥轻/中/重皮，挂 AH 或卖店均稳赚。
   * **采药**：利用豹形态高机动顺路采魔皇草、石南草、跌打草、雨燕草（石南草与雨燕草为敏捷/加速药剂刚需，AH 整组高价）。
   * **40 级/满级转型**：攒够买马及双天赋资金后，可将【剥皮】洗为【炼金术】，产出合剂/精油配合无限服**露营篝火**吃全队增益。
2. **拾取与清包策略**：
   * **人形怪必摸**：掉钱币及亚麻布/毛料/丝绸，攒满 20 个整组挂 AH。
   * **售店 vs 挂 AH**：灰色杂物、普通绿色武器（双手武器卖店极高）及杂属性绿装直接卖店；“猛虎/灵猴/雄鹰之”优质后缀绿装与紧俏白材（珍珠、元素火焰/土、大颗獠牙、厚毛皮等）挂 AH。
   * **肉类烹饪**：野兽肉烤熟再卖店，卖价更高且顺带练烹饪。
3. **顺路高收益刷金点（手头紧时可多停 20～30 分钟）**：
   * **15～18 级 · 西部荒野海岸线**：刷鱼人掉布料与蚌壳（开珍珠），兼开漂流箱。
   * **22～26 级 · 湿地东部红龙雏龙**：稳定产皮/肉，极低概率掉落高价稀有宠物【红龙宝宝】。
   * **28～32 级 · 暮色森林食人魔洞 / 荆棘谷北部**：人形怪密集产丝绸与绿装，猫德潜行挑落单打几乎零消耗。
4. **前期省钱两大禁区**：
   * **只学核心技能**：仅学熊/猫形态技能、回春术、治疗之触、荆棘术、野性印记、精灵之火；**跳过**月火术、愤怒、星火术、安抚动物、休眠、愈合等平衡/高耗蓝技能，到 30 级可省十几金。
   * **不频繁洗天赋**：严格按野性升级天赋点，省下递增洗点费留买小马。

## 动作条配置

核心逻辑：**形态专属输出放动态栏，全形态通用功能放固定栏**，避免变身时技能错位。

### 一、 动作条分工

| 动作条类型 | 切换特性 | 放置内容 | 推荐键位 |
| --- | --- | --- | --- |
| **主动作条（编号 1）** | **随变身自动切换**<br>（人/熊/猫/潜行各有独立页面） | **当前形态专属技能**<br>• 人形态：回春、愈合、治疗之触、月火<br>• 熊形态：锤击、割伤、横扫、低吼、重击<br>• 猫形态：爪击、撕碎、凶猛撕咬、斜掠 | **`1`–`6`、`Q`、`E`、`R`**<br>（紧贴 `WASD`，切形态无需重新记输出键位） |
| **左下方动作条（固定栏）** | **永久固定不变** | **全形态通用核心功能**<br>• 一键变熊 / 一键变猫<br>• 智能移动形态宏（跑图/解定身）<br>• 野性冲锋宏、树皮术宏、吃喝/药水 | **鼠标滚轮上/下**（切熊/切猫）、**`F` / 侧键**（移动解控）、**`Z`、`X`、`C`、`Shift+1~4`** |
| **右侧/边缘动作条** | **永久固定不变** | **非紧急辅助功能**<br>野性印记（爪子）、荆棘术、复活、炉石 | 无需绑定快捷键，鼠标点击即可 |

### 二、 快速设置步骤

1. **开启额外动作条**：`Esc` -> **选项 -> 动作条**，勾选 **“左下方动作条”**。
2. **绑定快捷键**：**选项 -> 按键设置 -> 动作条**，将主栏扩展位与左下动作条绑定为 `Q/E/R/F/Z/X/C`、`Shift+1~4` 及鼠标滚轮/侧键。
3. **分形态填充主栏**：在安全区依次切为人、熊、猫、潜行状态，从 `P` 键法术书将对应专属输出/治疗技能拖入主动作条 `1`–`6` 格子。
4. **开启自动自我施法**：**选项 -> 战斗** 勾选 **“自动自我施法”**，确保无目标按治疗技能直接加给自己。

## 实用宏

1. **三合一移动形态**（水栖/室内猎豹/室外旅行，连按解定身减速）
```lua
#showtooltip
/cancelform [swimming,noform:2][noswimming,indoors,noform:3][noswimming,outdoors,noform:4]
/cast [swimming] !水栖形态; [indoors] !猎豹形态; !旅行形态
```

2. **熊 / 猫一键互切**
```lua
#showtooltip
/cancelform [noform:1,noform:3]
/cast [form:1] 猎豹形态; 巨熊形态
```

3. **树皮术 + 自然之握二合一**（全形态可用，Shift 放自然之握）
```lua
#showtooltip [mod:shift] 自然之握; 树皮术
/cast [mod:shift] 自然之握; 树皮术
```

4. **变猫 + 潜行**（非战斗防误触，连按两下）
```lua
#showtooltip 潜行
/cast [noform:3] 猎豹形态
/cast [form:3,nocombat] !潜行
```

5. **潜行毁灭 / 常规撕碎二合一**
```lua
#showtooltip [stealth] 毁灭; 撕碎
/startattack [nostealth,harm,nodead]
/cast [stealth] 毁灭; 撕碎
```

6. **鼠标指向变熊野性冲锋**（打断/救场）
```lua
#showtooltip 野性冲锋
/cancelform [noform:1]
/cast [noform:1] 巨熊形态
/cast [@mouseover,harm,nodead][harm,nodead] 野性冲锋
```

7. **鼠标指向低吼**（熊坦防 OT 嘲讽）
```lua
#showtooltip 低吼
/cast [@mouseover,harm,nodead][harm,nodead] 低吼
```

8. **智能战复 / 脱战常规复活合一**（战斗复生 / 脱战起死回生）
```lua
#showtooltip [combat] 复生; 起死回生
/cancelform
/cast [combat,@mouseover,help,dead][combat,help,dead] 复生; [nocombat,@mouseover,help,dead][nocombat,help,dead] 起死回生
```

9. **鼠标指向回春术**（边跑边奶，可替换技能名）
```lua
#showtooltip 回春术
/cancelform
/cast [@mouseover,help,nodead][help,nodead][@player] 回春术
```

10. **鼠标指向驱除诅咒 / 驱毒术合一**（Shift 驱毒）
```lua
#showtooltip [mod:shift] 驱毒术; 驱除诅咒
/cancelform
/cast [mod:shift,@mouseover,help,nodead][mod:shift,help,nodead][mod:shift,@player] 驱毒术; [@mouseover,help,nodead][help,nodead][@player] 驱除诅咒
```
