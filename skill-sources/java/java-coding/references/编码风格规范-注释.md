# 编码风格规范 - 注释

## 一、类注释

概述 + 设计思路 + 配置示例

```java
/**
 * 搜索引擎服务切换实现类
 * 支持通过CacheService配置动态切换查询源（Solr/ES）
 *
 * 设计思路：
 * - 装饰器模式：包装SearchEngineService，加入切换逻辑
 * - 配置驱动：通过CacheService存储配置，实现动态切换
 * - 企业级粒度：以corpId+deployId为维度独立切换
 *
 * 配置示例：
 * cacheService.put(corpId + "_query_source_" + deployId, "es", 86400);
 */
```

## 二、方法注释

接口方法必须有完整 JavaDoc；实现类 @Override 方法无需重复注释；私有方法需要注释。

```java
// 接口方法
/**
 * 获取查询源配置
 * @param corpId   企业ID
 * @param deployId 业务对象ID
 * @return "es"表示ES查询，"solr"表示Solr查询，null表示未配置
 */
String getQuerySource(String corpId, String deployId);

// 私有方法
/** 构建缓存键 */
private String buildCacheKey(String corpId, String deployId) { ... }
```

## 三、字段注释

- `@Autowired` 注入字段：无需注释
- 常量字段：必须有注释，说明用途和格式示例

```java
/** 查询源配置缓存键前缀，完整键格式：corpId + "_query_source_" + deployId */
private static final String QUERY_SOURCE_CACHE_KEY_PREFIX = "_query_source_";
```

## 四、行内注释

方法内每一行代码都必须有注释，说明意图而非实现（3-12字），注释紧邻代码，无空行。

```java
// 获取查询源配置
String querySource = getQuerySource(corpId, deployId);
// 如果配置为ES查询
if (QUERY_SOURCE_ES.equals(querySource)) {
    // 执行ES分页查询
    return queryFromES(corpId, deployId, deploy, ...);
}
// 未配置或配置为Solr时，使用默认搜索引擎
return searchEngineService.getListWithPage(corpId, deployId, deploy, ...);
```

## 五、异常注释

catch 首行说明降级策略 + warn 日志 + 上下文参数。

```java
} catch (Exception e) {
    // 缓存读取异常时使用默认逻辑（Solr）
    logger.warn("获取查询源配置失败，使用默认逻辑: corpId={}, deployId={}, error={}", corpId, deployId, e.getMessage());
    return null;
}
```

## 六、TODO 注释

单独一行，说明待办事项，放在对应代码前。

```java
// TODO 默认是默认模板
String templateId = BusinessDeployConstants.DEFAULT_TEMPLATE_ID;
```
