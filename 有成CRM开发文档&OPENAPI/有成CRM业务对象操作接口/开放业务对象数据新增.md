# 开放业务对象数据新增

请求方式：post （[推荐接入V2版本](https://www.ycbg.com/help-center.html?tab=1&id=1217)）

请求参数数据类型：application/json

请求路径：/oapi/corp/v1/data/insert.json

请求参数：

| 参数 | 参数类型 | 必须 | 说明 |
|----|----|----|----|
| corpId | String | 是 | 企业ID |
| corpAccessToken | String | 是 | 访问企业数据合法性票据 |
| userId | String | 是 | 用户userId |
| deployId | String | 是 | 业务对象deployId |
| templateId | String | 否 | 单据模板ID 用于对数据的校验，如果未指定，则以系统预置模板(系统预置模板非默认模板)对数据进行校验 |
| data | Map | 是 | 业务对象数据 |
| relationDatas | Map | 否 | 关联子对象数据 |
| relationDatas.{子对象deployId} | List | 否 | 子对象数据 |

请求示例：

```json
{
"corpAccessToken": "{CORP_ACCESS_TOKEN}",
"corpId": "{CORP_ID}",
"userId": "{USER_ID}",
"deployId": "sale_order",
"templateId": "default_template",
"data": {
"order_title": "测试销售订单",
"customer_id": "408873",
"order_date": "2021/08/23",
"order_amount": "0.01",
"sale_order_decimal_0": "0",
"sale_order_decimal_1": "0"
},
"relationDatas": {
"sale_order_product_particular": [
{
"product_particular_id": 13069,
"product_particular_name": "测试产品明细0001[红色]",
"product_number": "2021-05-26-0002",
"special_tax_amount": "0",
"quantity": 1,
"product_unit_value": "block",
"product_unit": "块",
"unit_price": "0.01",
"product_price": "15.50",
"product_price_unit": "人民币",

}
]
}
}
```

响应结果：

| 参数    | 参数类型 | 必须 | 说明                       |
|---------|----------|------|----------------------------|
| apiName | String   | 否   | api名称                    |
| data    | Object   | 否   | 结果数据（对应新增数据ID） |
| essage  | String   | 是   | 提示信息                   |
| result  | int      | 是   | 状态码 100操作成功         |

响应结果示例：

```json
{
"apiName": "",
"data": {
"id": 80082
},
"message": "操作成功",
"result": 100
}
```
