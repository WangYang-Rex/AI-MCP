# 编码风格规范 - 方法结构

## 一、方法结构模式

**标准模式**：变量提取 → 异常判断 → 核心逻辑 → 返回结果

```java
public AIMeetingAnalyzerMarkRO markAnalyzerMeeting(CorpUserInfo userInfo, AIMeetingAnalyzerMarkPO markPO) {
    // ========== 第一阶段：变量提取 ==========
    String corpId = userInfo.getCorpId();
    String userId = userInfo.getUserId();

    // ========== 第二阶段：异常判断/参数处理 ==========
    if (Objects.isNull(dateFrom) && Objects.isNull(dateTo)) {
        Date now = new Date();
        dateFrom = AppDateUtils.startOfMonth(now);
        dateTo = AppDateUtils.endOfMonth(now);
    }

    // ========== 第三阶段：核心逻辑 ==========
    List<AIMeetingAnalyzerRecord> analyzerRecordList = aiMeetingQueryService.queryAnalyzerRecordList(...);

    // ========== 第四阶段：返回结果 ==========
    return AIMeetingAnalyzerMarkRO.builder().markList(markList).build();
}
```

## 二、变量提取规范

方法开头统一提取参数中的关键变量，每个变量单独一行 + 注释。后续使用局部变量，不重复调用 getter。

```java
String corpId = userInfo.getCorpId();   // 企业ID
String deployId = timelinePO.getDeployId(); // 对象ID
Long dataId = timelinePO.getDataId();   // 对象数据ID
CommonCheckUtils.StringNotBlank(deployId, null, "对象ID必须传递"); // 异常判断
```

## 三、方法命名规范

| 类型 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 生成/构建 | `makeXxx` | `makeAnalyzerTimelineRecordItem` | 构造、组装、转换数据 |
| 查找/获取 | `findXxx` | `findAnalyzerRecord` | 查找单个对象，可能返回null |
| 查询列表 | `queryXxxList` | `queryAnalyzerRecordList` | 查询多条数据列表 |
| 精确获取 | `getXxx` | `getAIMeetingAnalyzerAsstDataRecordByKey` | 按Key精确获取，必返回 |
| 执行操作 | `executeXxx` | `executeAsst` | 执行业务流程 |
| 更新操作 | `updateXxx` | `updateAnalyzerAsstRecord` | 更新数据 |

## 四、空值判断

按类型选择：对象用 `Objects.isNull/nonNull`，集合用 `CollectionUtils.isEmpty/isNotEmpty`，字符串用 `StringUtils.isBlank/isNotBlank`。

```java
if (Objects.isNull(deploy)) { deploy = businessDeployProcessor.findBusinessDeployObject(corpId, deployId); }
if (Objects.nonNull(genResult) && Objects.nonNull(dataRecord.getRelationDataId())) { ... }
if (CollectionUtils.isEmpty(startRecordList)) {
    // 中断流程
    throw new ParameterException("已有进行中的会议");
}
if (StringUtils.isNotBlank(recordTitle)) { ... }
```

## 五、三元运算符

保持单行，仅用于简单条件赋值；禁止嵌套三元。

```java
recordTitle = StringUtils.isNotBlank(recordTitle) ? recordTitle : conferenceTitle;
return Objects.isNull(charger) ? null : charger.getUserName();
```

## 六、异常判断中断流程

异常判断后紧跟"中断流程"注释，说明处理方式。

```java
if (Objects.isNull(genDTO)) {
    // 中断流程
    return null;
}
if (CollectionUtils.isEmpty(userIdList)) {
    // 中断流程
    return Pair.of(Lists.newArrayList(), Maps.newHashMap());
}
```
