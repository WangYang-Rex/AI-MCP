# 编码风格规范 - 命名

## 一、类命名

| 类型 | 后缀                       | 示例                           |
|-----|--------------------------|------------------------------|
| Controller | `XxxController`          | `OrderController`            |
| Service 接口 | `XxxService`             | `OrderService`               |
| Service 实现 | `XxxServiceImpl`         | `OrderServiceImpl`           |
| DAO | `XxxDao`                 | `OrderDao`                   |
| DTO | `XxxDTO`                 | `OrderQueryDTO`              |
| VO | `XxxVO`                  | `OrderDetailVO`              |
| PO | `XxxPO`                  | `OrderPO`                    |
| RO (请求对象) | `XxxRO`                  | `OrderCreateRO`              |
| 枚举 | `XxxType` / `XxxStatus`  | `OrderStatus`、`RiskType`     |
| 工具类 | `XxxUtils` / `XxxHelper` | `DateUtils`、`BizCheckHelper` |
| 常量类 | `XxxConstants`           | `BusinessDeployConstants`    |
| 异常类 | `XxxException`           | `ParameterException`         |

## 二、变量命名

- 使用驼峰命名（camelCase），禁止拼音和中英混合
- 布尔变量以 `is`/`has`/`can` 开头：`isValid`、`hasPermission`
- `Map` 变量使用复数形式并以 `s` 结尾，禁止使用 `Map` 后缀：`users`、`depts`
- `List` 变量使用单数元素名 + `List` 后缀，禁止仅使用复数形式：`userList`、`deptList`
- `Set` 变量使用复数形式或单数元素名 + `Set` 后缀：`userIds`、`deptIdSet`
- 对外协议、序列化或框架固定字段优先保持契约名称，局部变量和内部字段仍遵守上述规则
- 避免单字母命名（循环变量 `i`/`j` 除外）

## 三、常量命名

全大写 + 下划线分隔，语义完整。

```java
/** 默认分页大小 */
public static final int DEFAULT_PAGE_SIZE = 20;
/** 查询源配置缓存键前缀 */
private static final String QUERY_SOURCE_CACHE_KEY_PREFIX = "_query_source_";
```
