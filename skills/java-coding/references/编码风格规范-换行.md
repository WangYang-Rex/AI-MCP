# 编码风格规范 - 换行

## 一、换行阈值总览

| 场景 | 换行阈值 |
|------|----------|
| Builder | 字段 > 10 个 或 字符 > 200 |
| Stream / Lambda | 字符 > 200 |
| 方法调用 | 参数 > 8 个 或 字符 > 200 |
| 注解参数 | 参数 > 7 个 或 字符 > 150 |
| 返回语句 / 方法链 | 字符 > 200 |

**核心原则：优先单行，超过阈值才换行。**

## 二、Builder 换行

```java
// 单行：字段 ≤ 10 且 字符 ≤ 200
AIMeetingCreatorContext context = AIMeetingCreatorContext.builder().userInfo(userInfo).recordTitle(recordTitle).conferenceTitle(conferenceTitle).cnfId(cnfId).config(config).analyzerRecord(analyzerRecord).build();

// 换行：字段 > 10 或 字符 > 200
AIMeetingAnalyzerViewRO result = AIMeetingAnalyzerViewRO.builder()
    .userInfo(cnfUser).conferenceTitle(conferenceTitle)
    .analyzerRecord(new AIMeetingAnalyzerRecordVO(analyzerRecord))
    .memberList(memberList).videoList(analyzerVideoList)
    .asstList(asstDTOList).asstSkillRecords(asstSkillRecords)
    .skillRecordList(skillRecordList).taskList(taskList)
    .configList(configList).extraData(extraData).build();
```

## 三、Lambda 和 Stream 换行

```java
// 单行：字符 ≤ 200
List<String> userIdList = ListUtils.stream(userInfoList).map(CorpUserInfo::getUserId).filter(StringUtils::isNotBlank).distinct().collect(Collectors.toList());

// Lambda 内有逻辑时保持单行（即使稍长）
List<Pair<String, String>> markList = ListUtils.stream(dateRiskGroup.keySet()).map(dataRiskKey -> {
    List<String> dataRiskList = dateRiskGroup.get(dataRiskKey);
    return Pair.of(dataRiskKey, dataRiskList.contains(AIRiskType.HAVE_RISK.getKey()) ? AIRiskType.HAVE_RISK.getKey() : AIRiskType.NONE_RISK.getKey());
}).collect(Collectors.toList());

// 换行：字符 > 200
List<AnalyzerSearchUserItem> userItemList = ListUtils.stream(userInfoList)
    .map(user -> makeAnalyzerSearchUserItem(user, analyzerRecordGroup, asstTextRecordGroup))
    .filter(item -> item.getRecordList().size() > 0)
    .sorted(Comparator.comparing(AnalyzerSearchUserItem::getUserName))
    .collect(Collectors.toList());
```

## 四、注解参数换行

```java
// 单行：参数 ≤ 7 且 字符 ≤ 150
@DubboService(interfaceClass = AIMeetingAnalyzerService.class, registry = {"yc"}, retries = 0, timeout = 180000)

// 换行：参数 > 7 或 字符 > 150
@DubboService(
    interfaceClass = AIMeetingAnalyzerService.class,
    registry = {"yc", "internal"}, retries = 0, timeout = 180000,
    check = false, async = true, loadbalance = "roundrobin", actives = 10
)
```

## 五、方法链式调用换行

```java
// 单行：字符 ≤ 200
genResult.setDeployId(deployId).setTemplateId(templateId).setDataId(dataId).setGenStatus(AIMeetingSkillGenStatus.SUCCESS);

// 换行：字符 > 200
asstDataRecord.setRelationDeployId(deployId)
    .setRelationTemplateId(templateId).setRelationDataId(dataId)
    .setRelationDataContent(CastUtils.castJsonString(dataRecordContent))
    .setRecordStatus(AIRecordStatus.END.getKey()).setChangerId(userId).setModified(updateTime);
```

## 六、多参数方法调用换行

```java
// 单行：参数 ≤ 8 且 字符 ≤ 200
List<AIMeetingAnalyzerRecord> analyzerRecordList = aiMeetingQueryService.queryAnalyzerRecordList(corpId, dateFrom, dateTo, null, null, Lists.newArrayList(userId));

// 换行：参数 > 8 或 字符 > 200
List<AIMeetingAnalyzerAsstDataRecord> dataRecordList = aiMeetingQueryService.queryAnalyzerAsstDataRecordList(
    corpId, cnfId, null, null, AISkillType.ANALY.getKey(),
    null, null, null, null, CommonConstants.FIRST_PAGE, CommonConstants.DEFAULT_PAGE_SIZE
);
```

## 七、异常判断换行

异常判断中的 return/throw 必须换行，并在中断语句前添加“中断流程”注释。

```java
if (CollectionUtils.isEmpty(startRecordList)) {
    // 中断流程
    throw new ParameterException("已有进行中的会议");
}
if (Objects.isNull(genResult)) {
    // 中断流程
    return null;
}
```

## 八、空行规则

- 方法之间：1 个空行
- 逻辑块之间：无需额外空行（行内注释已分隔）
- import 块之后：1 个空行
- 类定义之前：1 个空行
