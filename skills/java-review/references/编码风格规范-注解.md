# 编码风格规范 - 注解

## 一、类注解顺序

Lombok → Swagger → 继承

```java
@Data @NoArgsConstructor @AllArgsConstructor @SuperBuilder
@ApiModel(description = "历史会话记录DTO")
public class AIChatHistoryDTO implements Serializable { ... }

@Getter @Setter
@ApiModel
public class CorpQuotation extends BusinessDeployBasePojo { ... }
```

## 二、各类型注解组合

| 类型 | 注解组合 | 说明 |
|------|----------|------|
| DTO | `@Data + @NoArgsConstructor + @AllArgsConstructor + @SuperBuilder` | 纯数据传输，继承用SuperBuilder |
| POJO | `@Getter + @Setter` | 便于特殊getter逻辑覆盖 |
| Service | `@Service("BeanName")` | 显式指定名称，与接口名一致 |
| 枚举 | 无类注解，key/val双字段 | 编码值 + 中文描述 |

## 三、字段注解顺序

Swagger → ES → JSON，每行一个注解。

```java
@ApiModelProperty(value = "报价单编号")
@Field(type = FieldType.Keyword, name = "quotation_number", store = true)
@JSONField(name = "quotation_number")
private String quotationNumber;
```

ES `@Field` 必填 type、name、store；Date 类型需指定 pattern。JSON `@JSONField` 蛇形命名映射数据库字段。

## 四、Swagger 注解要点

- 类级别：DTO 需要 description，POJO 继承基类可省略
- 字段级别：`hidden=true` 隐藏 serialVersionUID、临时字段、已废弃字段
